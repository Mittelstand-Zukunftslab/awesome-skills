# Awesome Skills ✨

> **Codifying craft, taste, and architecture for AI agents.**

A curated library of production-grade **AI Agent Skills** (`SKILL.md` standard) designed to turn AI coding assistants into senior design engineers, UI polish specialists, and fullstack architects.

---

## 💡 The Philosophy

Most code produced by AI agents is functional, but generic. It lacks **craft**—the subtle details of physical motion, optical typographic alignment, resilient API seams, and zero-debt architecture that separate good software from software people love.

**Awesome Skills** bridges this gap. By encoding established design engineering practices (Apple WWDC fluid motion, Emil Kowalski design principles, Vercel React patterns, Pit of Success API architecture), these skills give AI agents the contextual knowledge to:

1. **Prioritize Craft & Tactile Feel**: Build interfaces with interruptible spring animations, continuous touch feedback, and zero input latency.
2. **Design for the "Pit of Success"**: Construct APIs and component props where the obvious call is automatically the safe, bug-free call.
3. **Eliminate Common Anti-Patterns**: Ban brittle patterns like unnecessary `useEffect` calls in favor of derived state, key resets, and event handlers.
4. **Enforce Type & System Rigor**: Drive end-to-end type safety, modern database schemas, and structured fullstack architecture.

## 🧱 Skill Anatomy

Each skill in this repository follows the open `SKILL.md` format:

```markdown
---
name: skill-name
description: Clear, trigger-based summary explaining WHEN an AI agent should load this skill.
---

# Skill Title

## Core Rules & Guidelines
- Rule 1: Concrete, actionable guidance.
- Rule 2: Code examples demonstrating before/after states.

## Workflow & Step-by-Step Instructions
1. Step-by-step execution path for the agent.
```

- **YAML Frontmatter**: The `description` contains explicit activation triggers so AI agents match and auto-load the skill when relevant context is present.
- **Markdown Body**: High-density instructions, rules, anti-patterns, and code examples.

## 🚀 How to Use

### With Antigravity / Agentic Coding Tools
Place the repository or individual skill folders inside your project's agent configuration directory:

```bash
# Global skills directory
~/.gemini/config/skills/

# Or project-level skills directory
.agents/skills/
```

### With Claude Code / Cursor / Windsurf
Copy any desired skill directory into your repository's context/instructions folder (e.g., `.cursor/rules/`, `.claude/skills/`, or prompt instructions) to give your assistant instant domain expertise.

## 🤝 Contributing

We welcome contributions to expand and refine our skill library!

1. **Fork the repo** and create a feature branch (`git checkout -b skill/new-awesome-skill`).
2. **Create a directory** named after your skill (e.g., `my-skill/`).
3. **Add `SKILL.md`** with proper YAML frontmatter (`name` and trigger-focused `description`).
4. **Include references/examples** under `references/` if the skill contains deep documentation exceeding ~300 lines.
5. **Open a PR**!
